# Worklog

This section covers the **5-week** internship from **01/08/2026** to **27/09/2026** in the First Cloud AI Journey program at Amazon Web Services Vietnam Company Limited.

The first three weeks focus on core AWS services (account, EC2, S3, IAM, VPC). Week 4 covers serverless and monitoring while designing the API. Week 5 packages the app with Docker and deploys the Capstone project **CloudCV**, a CV parsing API running on Amazon EC2, storing data in Amazon S3, and calling a language model through Amazon Bedrock.

**Week 1 (01/08 – 14/08):** [AWS overview and practice account setup](1.1-week1/)

**Week 2 (15/08 – 28/08):** [AWS Core Services: EC2, S3, IAM](1.2-week2/)

**Week 3 (29/08 – 11/09):** [AWS Networking: VPC, Subnet, Internet Gateway](1.3-week3/)

**Week 4 (12/09 – 19/09):** [Lambda, Serverless, CloudWatch, CloudTrail; API design](1.4-week4/)

**Week 5 (20/09 – 27/09):** [ELB, Auto Scaling, Docker, and CloudCV deployment](1.5-week5/)
