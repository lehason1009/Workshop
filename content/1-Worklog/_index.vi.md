# Nhật ký công việc

Phần này trình bày quá trình thực tập trong **5 tuần**, từ **01/08/2026** đến **27/09/2026**, theo chương trình First Cloud AI Journey tại Công ty TNHH Amazon Web Services Việt Nam.

Ba tuần đầu tập trung vào các dịch vụ nền tảng của AWS (tài khoản, EC2, S3, IAM, VPC). Tuần 4 tìm hiểu serverless và các công cụ giám sát, đồng thời thiết kế API. Tuần 5 đóng gói bằng Docker và triển khai dự án Capstone **CloudCV**, một API phân tích CV chạy trên Amazon EC2, lưu trữ trên Amazon S3 và gọi mô hình ngôn ngữ qua Amazon Bedrock.

**Tuần 1 (01/08 – 14/08):** [Tổng quan AWS và lập tài khoản thực hành](1.1-week1/)

**Tuần 2 (15/08 – 28/08):** [AWS Core Services: EC2, S3, IAM](1.2-week2/)

**Tuần 3 (29/08 – 11/09):** [AWS Networking: VPC, Subnet, Internet Gateway](1.3-week3/)

**Tuần 4 (12/09 – 19/09):** [Lambda, Serverless, CloudWatch, CloudTrail; thiết kế API](1.4-week4/)

**Tuần 5 (20/09 – 27/09):** [ELB, Auto Scaling, Docker và triển khai CloudCV](1.5-week5/)
