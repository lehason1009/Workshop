### Goal

Describe the architecture, request flow, and deployment results of **CloudCV**, a backend REST API that analyzes CVs with Docling and a language model on Amazon Bedrock.

## 1. Use Case and Solution

A client submits a PDF or DOCX file to the API. **FastAPI** validates the request, **Docling** converts the document to Markdown, and the application sends the content with a prompt to a model on **Amazon Bedrock**. **Pydantic** validates the extracted data against a fixed schema before it is returned.

CloudCV is a backend service with no user interface. It is exercised through Postman, curl, or the Swagger UI generated by FastAPI.

## 2. Architecture and Storage

- A Docker container runs the API on an **Amazon EC2** instance.
- **Amazon S3** stores source CV files and JSON results in a private bucket.
- **Amazon Bedrock** provides the language model used for extraction.
- An EC2 **IAM role** grants limited access to the project bucket and model.
- **VPC/Security Groups** control instance connectivity; AWS Budgets sends cost alerts.

## 3. Request Workflow

1. The client sends a CV and an `X-API-Key` header to `POST /cvs`.
2. The API authenticates the key and validates file type and size.
3. Docling converts the PDF/DOCX into structured Markdown.
4. The application invokes Bedrock and validates the JSON response with Pydantic.
5. The source CV and result are stored in S3; the API returns the CV ID and result.
6. Other endpoints list, retrieve, or delete processed CVs.

## 4. Deployment Scope

The report records EC2, Docker, FastAPI, Docling, Bedrock, S3, IAM, VPC/Security Groups, GitHub, and AWS Budgets. ECS/Fargate, ECR, ALB, Route 53, ACM, CodeBuild, and MongoDB Atlas are not part of the deployed CloudCV architecture.

## 5. Results

The API processed PDF and DOCX samples. Tests recorded 201 for success, 401 for a missing/invalid API key, 400 for unsupported file types, 413 for files larger than 5 MB, and 404 for an unknown CV ID. Extraction quality was reviewed manually on a small sample; no quantitative benchmark was performed.
